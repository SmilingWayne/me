# 关于写作、文字与高考作文

!!! note ""
    试着换了一种表达方式，以文字浇心中块垒，本来心情不是很好，写一些东西似乎能改善这个状态。原作于20260609。

前两天高考，看各种信息渠道有讨论高考作文的，摸摸下巴、摸摸脑袋，怀想了一下过去。

我高考时候还在用老的江苏卷方案，理科数学200分，填空题写错个开闭区间跟割肉似的，圆锥曲线设点设线求不动点，算满三页纸写个根号下371也要有一往无前的勇气。那个时候理科数学还有种叫附加题的东西，就记得身边有个附加题39/40的哥们总分怒砍 180+ 惊为天人，结果物化有个B，更加蔚为大观了，简直是制度的祭品！！

语文160分，作文就占了70分，这个更是槽点中的战斗机，先不谈阅读理解比抽象代数还要抽象，就说写个作文，主旨就跟开个泡泡玛特盲盒一样纯靠运气猜猜猜，堪称命题人海龟汤大作战，每年腐儒味极重，江南自古以来作为科举重地的保守陈旧气象令人叹为观止，万般皆下品惟有读书高，人人挤破了头要当人上人，每个人都等着一日看尽长安花，舞文弄墨，出拳没有章法！

高二时候有幸进到学校最 nb 的当时叫 “尖刀班” 的优等班，现在想来除了给我的青春蒙上一层难以求得面积的阴影并认识到了为数众多的潜在精神病患者外，印象最深的事就是每次贴班后面的考试排名我只需要从后往前从下往上找不出10个必然卷卷有爷名！！

抽象的是有段时间一群人在研究作文素材，本子上写的都是加缪里尔克尼采卡夫卡，文必称建安风骨竹林七贤乾嘉学派，不说斯特里克兰德就说甲壳虫格里高利，你说村上春树，老师觉得你在cos朴树，你写梵高，老师以为你在装赵高，你在试卷上吹牛我是现代的莫尔索，老师说你是不是想写现代艺术的毕加索！！所有人不管男女都号称自己在做杜丽娘的梦，一群胡子不刮脸也不洗的理科男高对着作文格子纸张口就来哇哇哇好一片姹紫嫣红都开遍好一片断井颓垣！！！上了大学读了本桃花扇读了本长恨歌读了本西厢记，我琢磨着幸好当时年少轻狂没读书没在作文里写李香君写杨贵妃写崔莺莺，要不然我用如此侮辱智商的文字写这些人物我这辈子要错过多少古典美学！！冷静下来一想阿西吧这些角色见不得正能量的台面都是什么赐死的贵妃乱离的秦淮八艳，老师看了以为你在谈银灰色琴搞亡国的靡靡之音！！！

<span style="color:#1E90FF;font-weight:bold">另一种装 x 的方式就是借物喻理，不讲人话，思路清奇、处处有“情趣”。从抽象概念谈起时，论据必扯到古风古色古香古装古琴古剧</span>，也不知道和想要表达的抽象概念有什么关系，硬扯就行了，装 x 的第一要义是自己要信这个，自己都不信怎么让阅卷人信！

**这里的重要心态是“傲慢”**：<span style="color:#1E90FF;font-weight:bold">写的时候就不长眼，讲话自然不上心</span>。国家兴亡算什么，儿女情长才是真，人人都是性转版辛弃疾，隐瞒晚上熬夜写数学题的事实硬说自己在挑灯看剑，看的不是剑是枯山水，是太湖石，是敦煌画，是紫砂壶！再扯扯就怕看着金瓶梅也能独傲寒江雪了，为啥要这么写因为这些才是被功利的浮躁的算法社会忽略的中国非遗艺术哇！！是苏州的评弹南京的云锦扬州的蟹黄包啊！孔庙妈祖弥勒佛耶稣基督都low爆了，什么意识形态，我不要意识形态我只要龙应台的目送和奶奶的招手！！为你，千千万万遍！！汪曾祺的鸭蛋吃了一万颗，黄山的迎客松招过一万遍手，鲁迅的孔乙己脱下了一万遍长衫，但是写下这屎山作文是历史第一遍！！每个人都见过几个清冷感拉满的撑着油纸伞走过青石板的温婉女孩，搞得每个看过你作文的人都以为那是啥国民女神暗恋对象或者同性情侣哇塞谁T谁P！！好一片壮丽的文化景观与时代症候！！泪目了，孩子们！原来雨的哲学，也是泪的形而上学！！

说到语文虽然这课最适合睡觉但是我现在可不困了，我就记得高二那个班语文老师搞过一个我现在感觉贼行为艺术的事，说让每个人准备一个关于时政 / 新闻 / 故事，课前开火车每次请一位幸运儿给全班同学分享，我记得我找的是那个谭医生发声吐槽了一下鸿茅药酒然后就被某省晶哥跨省缉拿关押几个月的新闻[^1]。我已经忘了咋讲的了，就记得讲完后全班哄堂大笑教室里充满了快活的空气，**长大了再看真丫的少不更事，把一个严肃甚至很恐怖的故事讲成了搞笑故事，天呐噜我可真是个行为艺术家**！

我早已经忘记我写过多么蠢的作文了，高三开学被末位淘汰滚蛋到一个弱一点的班级终于摆脱了吊车尾的命运，我整个人甚至都更加热爱文字了，这时候最大的打击依然来自我的语文老师，我就记得他某次考完指着我作文里“吊诡”这个词掷地有声地跟我说，“我觉得你这篇文章写得像网络小说”，这句话杀伤力有多强呢？咱先不谈议论文怎么像网络小说的，就这句话我这个没心没肺的家伙竟然记到了今天可见这个 x 是真伤到我了！

此公最大的历史功绩在于我妈拽着我找他帮看看志愿，他上来就把我的第一志愿也就是现在收养我的这所学校给删掉了，不留任何商量的余地言辞之激烈令我不解，理由是我幼小的哭泣的不抗压的脆弱心灵来这里一定会得抑郁症的！！孩子你承受不住，会被开除的！！别躯体化了孩子，你一直在哭！！更吓到我不敢说话的是此公建议我别管高出分数线的数十分了速速赶赴东南地区 X 校某金融类专业就读吧，二十一世纪是金融的世纪！！前后语言之反差令我觉得他大概率可能是被夺舍了，要么就是他收了 X 校钱了！！群号是什么我也要进！！怎么我校不给我钱做推广！！

好了好了严肃一点。这篇小文章题目是写作，原计划是要讲作文。因为我虽然记不住我以前写过的那些杂七扭八的犄角旮旯玩意儿，但是我清楚记得我高考时候写了啥。我那年的题目是盐掺水水和盐，盐水水盐，变化来变换去，调和来调和去，叽里咕噜。我记得我写的是儒家。我甚至记得我的题目，非常装 x ，非常没意思，叫“**千年儒术，调和为本**”，大意是我觉得，诶！咱这个孔老夫子牛 x，儒生yyds，博采众长，发扬光大，左牵黄右擎苍，外儒内法，排老抑佛，从董（仲舒）哥到朱（熹）哥陆（九渊）哥，两千多年的思想家我都叫一声哥哥好！！哥几个无不把咱这老祖宗智慧发扬光大，所谓含英咀华，所谓智在调和：这不就是一种水放盐盐加水的智慧吗！！儒家之所以走到现在，即使被打倒孔家店了，新文化运动都快把人祖坟刨烧了几百回了，现在人们依然仁义礼智信，高考前曲阜都快成圣地了，这不就是一种调和的智慧吗！！然后文末再来个政治挂帅，思想的舵手出现了，极速夸赞一下中华文明的伟大，啊！我的祖国，牛x！顺带叠个甲，把自己涂成红色的苗，确保一下没有意识形态问题——一篇文章就结束了。

这事情非常抽象，<span style="color:#32CD32;font-weight:bold">我记得那么深，不是因为我觉得自己牛 x ，纯粹是因为我没时间写了</span>，写得很匆忙，顾不上美观，穿上儒生的衣服就是一阵附庸风雅，戴着偷来的芝麻官帽冒充所谓封建卫道士和思想传声筒。鲁迅批判的那种所谓意识形态保守分子与代言人，大概就是我这个色的，墙头草随风倒，让你捧儒家的臭脚！！唉！！

我不知道这作文最后给的咋样，但是我挺不可思议最终写了这个故事的。我当时的感受是它并不太符合我的写作气质（并且我现在已经完全不记得当时写作风格了），而我在彼时认为的最重要的考试里，临场应变之下，写的就是这么一个有些不合气质的东西。

上面我花了非常非常多篇幅，想要从我稀薄的大脑空气中找到过去记忆的蛛丝马迹，但是其实最后落到纸上的，是一个非常奇怪独特的东西。

我更加想说的事是，在读上面的内容时，我渐渐意识到我已经成了那个自己以前非常瞧不起的“老登”了，拿自己的“过去“开涮：老师傅坐下抽起了一根烟，聊起了从前，我竟然也掉到这个洞窟里了。

更可怕的是我无时无刻不意识到，当我把这些在洞窟里找到的的记忆碎片复原出来写下来的时候，<span style="color:#32CD32;font-weight:bold">他们早就不是原来的纯粹的“记忆”这个东西了，他们成了一种“装点门面”的玩意，变成了可以被现在的我用来 证明/展示/暗示 我当下或者过去未曾表达的的某个状态/观点/看法/立场/利益 的一种载体</span>，尽管我自己从出发点上看，并没有这个目的和意图。

当我写下并记叙这些东西的时候，当它们真的以“真实的记忆”存储并被我写下来的时候，它们真的还只是记忆吗？我是不是在利用它们表达些什么？我在反应不满么？我在表达对某些人的厌恶么？我在戏谑么？为什么我要用这样的语气而不是那样的语气？还是说，我在刻意用这种语气去表达，“我其实已经不在乎了” 这个事呢？所谓预判了预判的的预判？

换句话说，站在七年后的现在，我该怎么证明自己写下这些东西时候，不是在用它们装点门面，夹带私货的呢？我能否准确地告诉读者，“这是我进行头脑记忆回溯时候记录的东西，请把它们当做我的脑电图看吧。”

对这个问题的思考迫使这篇小文以一个非常不那么好看的结尾结束了，那就是<span style="color:#32CD32;font-weight:bold">我选择以彻底的让步取消这些恼人的思考。我大胆的承认我所有的写作不过是我在特定时刻的“装点门面”罢了，它不纯粹，很邪恶地动用了各种扭曲讽刺的字眼，它不客观，字里行间充斥着一个阴湿青年唾沫横飞的抱怨</span>，它的状态很奇特，我知道我在描述A，但是我也意识到在别人看这些文字的时候ta可能觉得我可能在讲述B以及表达对C的情感，并且包含了对D的同情与E的期待，但是孰强孰弱，我究竟在表达什么，其实我自己也没有那么清楚，就好比，我对于这个门面到底是什么，<span style="color:#32CD32;font-weight:bold">其实作为作者，它自己也不知道。你读出什么就是什么吧，这是一碟饺子醋，孩子们，作者死了！！</span>如果你逼着作者给出一个解释，哈哈哈哈我仰天大笑，这段文字，他的作用仅仅是记录过去啊！！哈哈哈哈！！

但是别忘了，这只是一种“装点门面”的伪饰罢了。

# 能工智人的罪与罚

!!! note ""
    「我赞成弗兰肯斯坦，不赞成诺斯费拉图。」

如果说2024年我依然对AI的发展带有一种言说不清的暧昧混沌[^1]，那么2026年的我则是接受了我们这些能工智人的罪与罚——智能体时代了，人类还在抵抗么，还在哪里抵抗呢？

我不是AI的从业者或者研究人员，没写过AI论文，没豢养过什么大模型——我只是个偷盗了一些AI的名词装腔作势，借着AI的触手帮我干过活的，一个平凡的AI使用者。**我对人工智能大人犯过的最大的错误，就是骂过它几句：「怎么这么蠢！」**。我真诚地祈祷自己不会因言获罪，法不及过往，==在AI伦理法庭上，我祈求AI审判官高抬贵手，不要判处我剥夺AI使用权终身的刑罚==。

略过唠叨，今年以来，我依然感受到了日趋严峻的「存在主义危机[^2]」。迎合一下时兴的术语，这应该算「==瘫坐在椅子上，仿佛看到核弹爆炸==」。能意识到这个状态，纯粹是我猛猛然发现人类真的太微不足道了。**生物学意义上说，智人是地球上8种人科动物里唯一一种被 IUCN[^3] 归纳为「无危」的动物**，狭小的地球，供养了近80亿个智人！作为对比，分布第二广的人科动物是西部大猩猩，它以现存20万只左右的规模被归为「极危」动物！

或许人类早该认识到自己的毫无价值。「价值」这个事堪称最伟大的衔尾蛇定义。人类之所以能被认定为有价值，是因为人类自己定义自己有价值。蝗虫也可以被认为是有价值的，只不过过境时，它在人类的语境下毫无价值——

**那么在AI的语境下里，人类是有价值的么？在那些庞大参数向量组成的高维空间里，人工智能大人们是怎么看待我们这些能工智人的价值的**？人类误以为费尽心机编织的精巧的后训练大网与能力对齐能够强行矫正AI大人的情绪与行为基础，却忘记了这完全是痴人说梦——既然走到这了，==嗜血的诺斯费拉图是不会停下的，它会撕咬并吮吸一切==。

你看，人类早该认识到，<u>击败人类所需的操作单元，就是这些如此基础的矩阵运算</u>。这些运算居然能包含了如此巨大的应用价值，为了满足这些矩阵运算，竟然诞生了如此多的工程细节与技术优化，脱下科技的长衫，这些奇怪的吐出Token的怪兽，靠着一阵风潮，引得了如此多的资本、投入、关注度，抬高了多少股价，又抬走了多少创业者。人类的本性一次次重演，舞台的演员换了一茬一茬，座位上的观众走了一波一波，故事还在发生。

我像是看幻灯片切换一样看着一切闪过。我意识到自己在做的不过是喃喃自语那些含糊不清的名词：

Codex, Claude, Harness, Agent, Loop, Tools, Skills, MCPs, KV Cache, Coding, Seedance ... 

在那一个失去语言表达力的瞬间，我猛然想起，人工智能对人类的罚，只是一种心理上的折磨与剥削。

**在那些AI的话语不存在的场合，人类还在屠杀同类，还在救死扶伤，还在相信爱情，还在相信信仰，还在看潮平潮落和云卷云舒**。

你不能因为人类在用AI杀人，就说人类快灭亡了。你不能说几个亿的Token 可以烧穿 Navier-Strokes ，就认为人类是一群即将被赶尽杀绝的混蛋。

因为人类不要脸，能工智人们掌握着自如地切换到「低人权优势」的心理预期：诶，我就是烂，我就是xxx，我就是蠢，怎么，你不服气？ 嘿嘿！

「效率」可以替代一切，但是人还要寄居蟹般涌到那些犄角旮旯里苟延残喘，==干那些迂笨陈旧的事==，停留在过去，直到大浪涌来再拥抱改变；「生产」是一种奠基性的历史唯物主义范畴，但是人依然撒泼打滚似地挤满了机械齿轮的夹缝。==人类灵活的道德底线、多变无踪的感性存在，让这种生物在不要脸与摆烂上达到了宇宙意义上的惊世骇俗==。人类之所以存在，并不因其伟大，而因其过于无耻、懦弱、卑贱和甘作奴仆。

换言之，一万个卑躬屈膝，抵不过一句「千淘万漉虽辛苦，吹尽狂沙始到金」。人类的后验知识里一定有一条 **「瞧得起自己」** 。心比天高，命比纸薄，那都是瞧不起自己的文人卖弄风骚，广大的能工智人们，==心比纸薄，命比天高，管什么雨打风吹去，只要太阳还在照常升起，还有什么不能睡一觉就解决呢？如果不行就睡两觉吧！==

最初，我认为人类这种「向下兼容」与道德底线是一种劫罚，长大后我才发现，自己是一见杨过终误身——这是人类最宝贵的财富。

这个节骨眼，如果你问我，人类应该如何在这个智能体时代幸存，人类该如何证明自己的价值，凡此种种，或许我会说：

① 人类的价值是不言自明的，为什么需要证明？谁来证明你证明的价值就是真正的价值？你怎么知道你以为的价值就是别人以为的那个价值？

② 管什么洪水滔天满地黄沙，管什么金星凌日彗星上行，管什么脂浓粉香两鬓成霜，做那些摆烂的事，过那些摆烂的日子去吧：**以前做什么，现在还做什么**，<u>梳妆打扮，结社交友，阅读写作，周游列国；上九天，下五洋，看不见的角落，蛇依然在蜕皮，蝉依然在脱壳；摸不到的地方，恋人依然在相爱，仇雠依然在相杀。就让一切都和AI占领之前那样。相比于被人工智能大人奴役，为什么不去做一个消费主义的奴隶呢？为什么不去当一个笨拙的古法的工匠？为什么不去做一个被感情欺骗的人呢？又或许，为什么一个人不可以选择甘愿被AI淘汰，甘愿走向AI创造的毁灭呢？这之间又有什么高贵之分，这前后又有什么等级之差呢？</u>

陀思妥耶夫斯基用拉斯柯尔尼科夫的故事描述了「罪与罚」，但他的字里行间分明在讨论「拯救」以及他对拯救的构想，分明在描摹不堪背后的改悔、折磨云云，今晚我猛然间理解了这种写作惯性。人人心里都有一个负责拯救的形象，救世主、圣母，抑或是其他抽象概念，而我分明在写AI对能工智人的罪与罚，为什么我依然在探讨能工智人的自我拯救呢？

我认为这是我的拉斯柯尔尼科夫时刻。

# 西方艺术笔记 I 


## 希腊艺术

前4世纪的希腊艺术达到了高峰。从艺术文化上看:

| 风格           | 流行地区                       | 特点                                           |
| -------------- | ------------------------------ | ---------------------------------------------- |
| **爱奥尼亚式** | 靠东方沿海的城邦               | ==柔和活泼，倾向于女性美==                     |
| **多立克式**   | 靠南方大陆的城邦               | ==强硬坚实，倾向于男性美==                     |
| **阿提克式**   | 希腊半岛中间、以雅典为首的城邦 | ==综合了爱奥尼亚和多立克两者的特长而创造出来== |


---

希腊的**建筑庄重平稳**，在和谐的比例中显出一种自然的生命美。后人把希腊的建筑主要组成部分的柱子按样式分为三种风格：

| 柱式           | 特点                                                         | 柱身                                                               | 柱头                                       |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------------ | ------------------------------------------ |
| ==多立克==式   | **雄浑、单纯、刚健，倾向于男性美**                           | 中间微凸，像是为了承重压力而鼓足力量；周围垂直的沟凹使柱身增加变化 | 大出一圈的圆顶，好像在压力下自然胀出的部分 |
| ==爱奥尼亚==式 | 轻快柔和精致，倾向于女性美                                   | 细长，柱脚垫起几层圆盘                                             | 变得更大，并向左右盘旋成两个涡纹           |
| **科林斯**式   | 出现于商业繁荣的科林斯城；失去了沉重的意味，显得为装饰而装饰 | —                                                                  | 以纤巧的树叶和花蔓组成的华丽装饰           |

## 拜占庭

在美术上，**拜占庭的作品更多地汲取了东方艺术中重象征和装饰的手法**，这更符合宗教意识的要求。查士丁尼即位后，查封了雅典的哲学学校，以杜绝异教思想的传播。而在8世纪开始，基督教世界内部又开始了100多年的破坏圣像运动。

## 哥特式

美术史上，人们把12世纪前后以建筑样式的变化而开始的艺术风格称为哥特式艺术。

| 对比项     | 罗马式教堂                     | 哥特式教堂             |
| ---------- | ------------------------------ | ---------------------- |
| 线条与拱券 | 以水平线和圆的拱券为主         | 以尖顶拱券和垂直线为主 |
| 整体观感   | 宽阔平稳，但不免有沉闷呆重之感 | 高耸轻盈，富丽精致     |
| 墙壁       | 墙壁占面积大                   | 除门窗几乎没有墙壁     |
| 装饰与绘画 | 更倾向于城市化和几何图案       | 更强调生活的真实感     |
| 著名例子   | 意大利比萨斜塔主教堂           | 巴黎圣母院、米兰大教堂 |

## 文艺复兴

### 意大利

波提切利（1445~1510）《维纳斯的诞生》。人们认为这个维纳斯是著名的美女西蒙奈塔，她16岁嫁给佛罗伦萨的官员维斯普奇，不久就被美第奇的弟弟朱利阿诺看中并选为情人，22岁时在选美会上当选为女王，可是第二年就抱病而亡。她出殡时没有用棺椁，而是让她仰卧在车上，围以鲜花，全城人观看后无不哀婉叹息……

十四世纪以后，艺术已经不仅仅是宗教的奴婢，艺术家也不仅仅以教堂作为他们唯一的雇主和保护人。他们的雇主多半是像美第奇家族这样从市民阶级出身，因经商致富，靠资财和权术攫取到政权的新贵族。

1494年，美第奇家族因投靠法国侵略军而遭佛罗伦萨人民驱逐。维护穷人利益的僧侣**萨伏那洛拉**成为领导者时，波提切利站在了他那边。尽管萨伏那洛拉为了端正道德，连古典文化和人文主义的文学艺术都加以焚毁，但波提切利仍对他深表同情。四年后，萨伏那洛拉被复辟的美第奇家族和罗马教皇判罪，烧死在佛罗伦萨。

**宗教生活仍然是十五六世纪欧洲人生活中的重要部分。不过人们需要的是一种更近于人情和人性的基督和圣母**，这是与希腊古典观念相符合的……拉斐尔……创作的圣母形象已经远非中世纪那种庄严的女王，而是典范的贤妻良母，或是温柔的母性。她们来自生活，又是作者按照人文主义的观点和审美的、古典的审美趣味加以理想化了的。拉斐尔在书信中写到：

“我为了创造一个完美的女性形象，不得不观察许多美丽的妇女，然后选出最美的那一个做我的模特……” 他的作品也被称为一种：“秀美”的风格。

把美从神权的枷锁中解放出来，这是反神学的胜利，是以唯心的新柏拉图主义相对抗的胜利。（新柏拉图主义的普洛丁说过，肉体只是真理和灵魂的拙劣的模仿品。）

## 巴洛克


| 地区   | 人物       | 生卒年    | 代表作                                                           |
| ------ | ---------- | --------- | ---------------------------------------------------------------- |
| 意大利 | 卡拉瓦乔   | 1571~1610 | 《圣马太蒙召》、《以马忤斯的晚餐》、《大卫手提歌利亚的头》       |
| 意大利 | 贝尼尼     | 1598~1680 | 《圣特雷莎的狂喜》、《阿波罗与达芙妮》、《大卫》、圣彼得广场柱廊 |
| 尼德兰 | 鲁本斯     | 1577~1640 | 《劫夺吕西普的女儿》、《下十字架》、《玛丽·德·美第奇组画》       |
| 尼德兰 | 凡戴克     | 1599~1641 | 《查理一世行猎图》、《查理一世三面肖像》                         |
| 西班牙 | 委拉斯贵支 | 1599~1660 | 《宫娥》、《布雷达的投降》、《教皇英诺森十世肖像》               |

巴洛克特指的是一种艺术风格。严格来说，如果文艺复兴可以归之为古典主义，巴洛克则可以归之为浪漫主义。它之所以成为独特的风格，是由于它在精神、艺术精神和手法上与盛期的文艺复兴有着明显的区别。

(1) **卡拉瓦乔**用**聚集的强光**,塑造了暗室之中的人物形象。

(2) **鲁本斯**在油画技巧上的贡献是巨大的。他的巴洛克式**明暗对比、运动感很强的构图形式，尤其是在笔法上的力量和美**，给后来的浪漫主义以及印象主义都有启发借鉴的作用。

> 鲁本斯在**安特卫普**的工作室实际上是一个绘画工厂。他常常是亲手画一张速写式的油画小草图，然后让助手们分别在一幅放大的画幅上作画。有的专画人，有的专画景或道具，最后再由他动手修改和润色。所以以他的名义完成的作品数量十分惊人。

荷兰人民信奉新教（加尔文教派），独立后的荷兰人颇像英国的清教徒，生活俭朴、工作勤奋，**善于经营计算和积累财富**。社会的主要成员是**商人、手工业者以及在战争年代捍卫民族独立的民兵和军官们**。加尔文教派在宗教仪式上主张简约，不需要装饰华丽的大教堂，把艺术从教堂里解放了出来。

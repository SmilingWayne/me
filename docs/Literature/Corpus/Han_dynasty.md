# 两汉时期文、典故、意象、文学故事

<span style="color:orange;font-weight:bold">沐猴而冠</span>：比喻徒有其表、虚有其名，或本质卑劣却装扮成有身份、有地位之人，亦指目光短浅、难成大事的掌权者，含强烈贬义

> 字面拆解：沐猴（猕猴）+ 冠（戴帽子），意为猴子穿戴人的衣帽，终究不是真人

《史记・项羽本纪》载，秦末，项羽率楚军破咸阳，焚烧宫室、掠夺财宝，有人（史称韩生）建议他定都关中，凭借险要地势成就霸业。但项羽坚持东归，说 "富贵不归故乡，如衣绣夜行" 的名言。韩生私下感叹项羽 "沐猴而冠"，被项羽得知后惨遭烹杀。

<span style="color:orange;font-weight:bold">玄灞、素浐</span>：长安附近两个水名。灞水的水黑，故云玄灞；浐水的水白，故云素浐。二者均为渭水的支流。后来的"霸陵伤别"的霸陵，是西汉文帝刘恒的陵寝，临近灞水。

<span style="color:orange;font-weight:bold">终军</span> (140 BC — 112 BC)：字子云，济南人，少年英才、早逝志士，世称 "终童"。18 岁为博士弟子，受汉武帝赏识；20 余岁出使南越，为国殉难。

<span style="color:orange;font-weight:bold">西宾、东主</span>：，指《两都赋》中虚拟的对话人物，西部宾、东都主人。

<span style="color:orange;font-weight:bold">安处、凭虚</span>，指《二京赋》中的虚拟主人安处先生、凭虚公子。

<span style="color:orange;font-weight:bold">黄肠</span>：汉代墓葬制度以柏木的中心部分，在棺木四周垒砌成木墙，因柏木心呈黄色，故称黄肠。便房：墓室周围的走廊或小室，可供凭吊祭者休息。

<span style="color:orange;font-weight:bold">霍光</span>：西汉大臣，废昌邑王刘贺，立武帝孙刘询为帝，是为宣帝。

<span style="color:orange;font-weight:bold">南登霸陵岸，回首望长安</span>：东汉末年，王粲躲避荆州乱，惜别京都长安时，作七哀诗。

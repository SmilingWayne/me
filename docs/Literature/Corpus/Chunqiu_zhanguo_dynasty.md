# 春秋战国人文、典故、意象与文学故事

## 地理

<span style="color:#1E90FF;font-weight:bold">郑渠、白渠</span>：郑渠是战国时水工郑国为秦国所凿，白渠是汉武帝时白公建议开凿，引泾水灌溉关中平原。

<span style="color:#1E90FF;font-weight:bold">玄灞、素浐</span>：长安附近两个水名。灞水的水黑，故云玄灞；浐水的水白，故云素浐。二者均为渭水的支流。后来的"霸陵伤别"的霸陵，是西汉文帝刘恒的陵寝，临近灞水。

<span style="color:#1E90FF;font-weight:bold">崤函</span>，崤：崤山，也作崤陵。
在今**河南三门峡**境内，分东崤、西崤，秦岭东段支脉，山道狭窄险峻，自古为险要山地隘路。函：函谷关。古函谷关在今**河南灵宝**，扼守崤山要道；是战国、秦汉天下第一雄关。

<span style="color:#1E90FF;font-weight:bold">河洛</span>，**河：专指黄河**，**洛：专指洛水（洛河）**，黄河中游以南、洛水流域，核心就是今洛阳盆地一带，夏、商、周三代多建都于河洛，古文里常以「河洛」代指洛阳、中原王畿，文化上代指华夏正统文脉根源。

## 人文

<span style="color:orange;font-weight:bold">终军</span> (140 BC — 112 BC)：字子云，济南人，少年英才、早逝志士，世称 "终童"。18 岁为博士弟子，受汉武帝赏识；20 余岁出使南越，为国殉难。

<span style="color:orange;font-weight:bold">方叔、召虎</span>：均为周宣王的卿士，方叔先伐猃狁，后征荆蛮。召虎曾平定淮夷。

<span style="color:orange;font-weight:bold">和氏璧（荆山之玉）</span>：出自《韩非子・和氏》，讲述楚国人**卞和**（和氏）分别向楚厉王、武王、文王三献璞玉、两遭刖足，终得楚文王识宝的故事，象征真才被埋没、忠良遭误解。

<span style="color:orange;font-weight:bold">百里奚</span>：春秋时虞国大夫，晋灭虞后被俘，曾作为秦国夫人的臣子到秦国，后逃到楚国，穆公以五张羊皮将其赎回，百里奚非常感激。助穆公谋划大业，甚得信任。

<span style="color:orange;font-weight:bold">曜灵</span>：指太阳。<span style="color:orange;font-weight:bold">蒙汜</span>：古代称太阳沉没的地方。<span style="color:orange;font-weight:bold">望舒</span>：古代指月亮。

<span style="color:orange;font-weight:bold">钟子期与伯牙</span>：钟子期是春秋时楚国人，精于音律。伯牙鼓琴，志在高山流水，子期闻而知之。后来子期死，伯牙乃绝弦破琴，终身不复鼓琴。

<span style="color:orange;font-weight:bold">郑卫之音</span>：春秋战国时郑卫两地的俗乐，泛指淫靡之乐或俗乐。

<span style="color:orange;font-weight:bold">伊尹、周公（伊周）</span>：伊尹是商汤的相，辅佐商汤灭夏桀，周公曾辅佐成王灭商纣，此二人均为著名的贤明宰相。

<span style="color:orange;font-weight:bold">蹇叔</span>，秦国老臣。秦穆公曾派孟明视等人率军袭郑，蹇叔劝阻无效，遂临军而哭，言秦军将败于崤山，后果如其言。

<span style="color:orange;font-weight:bold">西宾、东主</span>：，指《两都赋》中虚拟的对话人物，西部宾、东都主人。

<span style="color:orange;font-weight:bold">安处、凭虚</span>，指《二京赋》中的虚拟主人安处先生、凭虚公子。

<span style="color:orange;font-weight:bold">子婴</span>：秦朝最后一个皇帝，乘着素车白马向刘邦投降，他以丝带系颈，脱去上衣，裸露肢体，以在谢罪时表示虔诚或惶恐。

<span style="color:orange;font-weight:bold">扶苏</span>：秦始皇的长子，因劝谏阻止焚书坑儒，被流放到北方。后来，李斯假传始皇之命杀扶苏。

<span style="color:orange;font-weight:bold">桑梓</span>：是古代住宅边常栽种的树木，后来遂以指代家乡、故乡。

<span style="color:orange;font-weight:bold">獭祭</span>：据说水獭捕到鱼，便将其排列在岸边，如有所祭，俗称獭祭。

<span style="color:orange;font-weight:bold">雍门周与孟尝君</span>：雍门周曾带着琴去见孟尝君，孟尝君对他说，<u>你能鼓琴让我悲伤吗？</u>雍门周回答，**千年万岁后，当荆棘长满您的坟墓，牧童在上面践踏并叹息说，尊贵如孟尝君者也难免于此啊**。孟尝君闻言，不禁热泪盈眶。雍门周引琴而鼓，孟尝君泪下如雨。

<span style="color:orange;font-weight:bold">文子、齿剑</span>。**文子是春秋时越王勾践的大夫文种，辅佐勾践灭吴**。后勾践听信谗言，命文种自杀。持剑由言出任，后言被杀或自杀为齿剑。

<span style="color:orange;font-weight:bold">黄肠</span>：汉代墓葬制度以柏木的中心部分，在棺木四周垒砌成木墙，因柏木心呈黄色，故称黄肠。便房：墓室周围的走廊或小室，可供凭吊祭者休息。

<span style="color:orange;font-weight:bold">骖</span>，同驾一辆车的三匹马，或曰古代马车上的左右边马称为骖。

<span style="color:orange;font-weight:bold">鸾</span>：结在马衔上的铃铛叫鸾。八鸾，一马有两个铃铛，四马有八个铃铛，故称八鸾。

<span style="color:orange;font-weight:bold">象舆</span>：象拉的车子，或曰以象牙为装饰的车子，为帝王所乘。

<span style="color:orange;font-weight:bold">簪履</span>：有一个妇人砍柴伐薪时丢了簪子，非常哀伤。孔子问其故，答曰：<u>非为簪也，为不忘旧物也</u>。

<span style="color:orange;font-weight:bold">郑女</span>：指郑袖，战国时楚怀王的王后，善歌舞，名曰郑舞。

<span style="color:orange;font-weight:bold">郝素</span>：古代弹琴的能手。

<span style="color:orange;font-weight:bold">沈诗任笔</span>：文学家**沈约**，南朝著名诗人，历任宋、齐、梁三朝。其诗着意雕琢，时号**永明体**，所创四声八病之说。以诗闻名，**任昉**，南朝文学家，历仕宋、齐、梁三朝，以善作朝廷表奏书记著称。当时王公表奏，朝廷文库，多出其手。

<span style="color:orange;font-weight:bold">怀鼠</span>：战国时，郑人称玉之未雕琢者为"璞"，而周人称未腊之鼠称为璞，又称"鼠璞"。

<span style="color:orange;font-weight:bold">四渎</span>：指江、淮、济、河，四条河。

<span style="color:orange;font-weight:bold">石崇</span>：晋国人，常抢劫远路客商致富，于河阳置**金谷园**，园中植果树数万棵，奢靡成风。

<span style="color:orange;font-weight:bold">五胡</span>：指西晋末年入侵中原的<span style="color:orange;font-weight:bold">匈奴、鲜卑、羯、氐、羌</span>五个少数民族政权。

<span style="color:orange;font-weight:bold">弄玉</span>：春秋时秦穆公之女。时有萧史善吹箫，作凤鸣。穆公遂以弄玉妻之，并造凤台让二人居住。一日吹箫引凤，夫妇二人共升天仙去。秦人作凤女祠于雍宫以祀之。

<span style="color:orange;font-weight:bold">椒房</span>：皇后所居宫殿，以椒和泥涂壁，暖而有香气，故称椒房。

<span style="color:orange;font-weight:bold"><span style="color:orange;font-weight:bold"></span></span>：传说中古代蜀国的帝王。<u>东周末年在蜀称帝，号曰望帝</u>。后归隐，让其位于其相开明。时值二月，杜鹃鸟鸣，蜀人怀之，因呼杜鹃为杜宇。

<span style="color:orange;font-weight:bold">巫山之女，高唐之姬</span>：宋玉的《高唐赋序》说：昔者先王尝游高唐，怠而昼寝，梦见一妇人，曰："妾巫山之女也，为高唐之客。闻君游高唐，愿荐枕席。"王因幸之。

<span style="color:orange;font-weight:bold">旦为行云，暮为行雨，朝朝暮暮，阳台之下</span>。这是《高唐赋序》中的原话，指**男女交欢之事**。

<span style="color:orange;font-weight:bold">高唐</span>：楚国台馆名，在云梦泽中。

<span style="color:orange;font-weight:bold">霍光</span>：西汉大臣，废昌邑王刘贺，立武帝孙刘询为帝，是为宣帝。

<span style="color:orange;font-weight:bold">南登霸陵岸，回首望长安</span>：东汉末年，王粲躲避荆州乱，惜别京都长安时，作七哀诗。

<span style="color:orange;font-weight:bold">伊阙</span>：山名，又称阙塞山、龙门山，在洛阳之南。

<span style="color:orange;font-weight:bold">柳下惠</span>，春秋鲁国大夫，因食邑柳下，谥号是惠，所以称柳下惠。他任士师时，因正直三次遭罢免。

<span style="color:orange;font-weight:bold">燕昭王与郭隗</span>：燕昭王在国家被齐国攻破以后即位，听从郭槐的建议，铸造黄金台，尊郭槐为师，于是天下贤士闻风而至。

<span style="color:orange;font-weight:bold">介之推、申包胥</span>：避而不受厚禄的故事：**介之推**跟随晋文公重耳逃亡共十几年，文公返国后，介之推为了避让文公对他的封赏，与母亲一起隐居绵山；**申包胥**，**春秋时楚国大夫**，伍子胥引吴兵攻入楚国都城郢都，申包胥到秦国乞援，哭了7天，使秦国终于出兵救楚（又称"<span style="color:orange;font-weight:bold">秦庭之哭</span>"），楚昭王赏他，他避而不受。


<span style="color:orange;font-weight:bold">"绝缨"</span>：据《说苑》记载，楚庄王与群臣饮酒，灯灭，一人拉了下楚庄王美人的衣服，美人将那人的冠缨拔了下来，让庄王追究。庄王反命暂不掌灯，让每个人都将帽缨摘下，尽欢而散。后来在一次与晋人的作战中，那人表现得非常勇敢。

<span style="color:orange;font-weight:bold">白虹贯日、苍鹰击殿</span>，异常天象，比喻大事发生。语出《战国策・魏策・唐雎不辱使命》。白虹贯日：
人物：**聂政**（韩国轵人，因杀人避仇至齐国，以屠宰为生）、**严遂**（韩卿，与韩相韩傀结怨）、**韩傀**（韩国相国）

经过：严遂以黄金百镒为聂政母亲祝寿，求其刺杀韩傀。<u>聂政因母亲健在拒绝，待母亲去世、姐姐出嫁后，孤身仗剑闯入韩傀府，刺杀韩傀后自毁面容、挖眼、剖腹而死，防止连累他人。</u> 据说行刺时候"白虹贯日"。

<span style="color:orange;font-weight:bold">苍鹰击殿</span>：

人物：**要离**（吴国刺客）、**庆忌**（吴王僚之子，武艺高强）、吴王阖闾（公子光，杀僚夺位）

经过：阖闾即位后，庆忌逃往卫国，招募士兵欲复仇。要离自请刺杀庆忌，采用苦肉计：让阖闾斩断其右臂、烧死其妻子，伪装成被追杀的逃犯投奔庆忌。庆忌信任要离，让其陪乘战船。要离趁庆忌不备，用短矛刺中其心窝。庆忌临死前赞叹要离是 "天下勇士"，下令放其回国。

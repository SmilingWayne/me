# 虞美人草

!!! note "说在前面"
    夏目漱石转向职业作家后的第一部长篇。文风浓艳雕琢，句法奇崛，通篇是写生文式的比喻与排比，读来既有《草枕》那样的俳谐风流，又有一种近乎舞台剧的夸张与紧张。==全书的主旨，照作者自己的说法，是“弄死藤尾”——一个把爱情当作自我欣赏的玩具、以美与诗趣为名而全无道义的女子。== 
    
    紫色是她的颜色，也是这场悲剧的颜色。

    ----

    夏目一贯的戴着显微镜和高速相机描写纤柔雅丽日式美学的小说，**看到最后非常非常不解，为什么现代人眼中如此敢爱的藤尾必须被作者写死，深度怀疑作者对“现代的爱”及其化身（藤尾）有一种莫名的恨意**，翻了些评论，大意指日本全盘西化时期作者的一种隐喻，而这种隐喻在全书里唯一的坦白是甲野这个富家子弟哲学家的书信，<u>生者唯有通过死亡才能知道所作所为的代价</u>。如此稍微挽尊一点的回答就是，==遵循“道义”（我必须加上引号）的小野与小夜子的结合就是圆满的吗？被过去裹挟，又在摩登浪潮下稍步青云就举手投降的、优柔寡断的小野，真的能维护好这段已经出现巨大裂痕、已经以生命为沉没成本的婚姻吗？==

    于南苑湿地公园书屋，3.5星。

    PS 系子与甲野的爱也充满了对新式生活的滤镜，这在现实面前如此不堪一击。

## 创作小史

!!! abstract "背景"
    - **1907年6月23日至10月29日**，连载于《朝日新闻》，凡十九话（连载体共一百二十七回）；翌年1月由春阳堂出版单行本。其时舆论喧腾：三越卖“虞美人草浴衣”，玉宝堂卖“虞美人草戒指”，报童沿街高叫“漱石的虞美人草”。
    - 标题取自末章一幅倒立的银屏风画，画的是虞美人草，落款“抱一”（酒井抱一）。小说常被指与梅瑞狄斯《利己主义者》、萨克雷《名利场》、奥斯汀《傲慢与偏见》有渊源；藤尾则一再以埃及艳后**克莉奥帕特拉**为喻。
    - 漱石写到中途便已厌弃，致信高浜虚子：“《虞美人草》已写腻了，真想早点把那女人杀掉。”又对友人明言：**“弄死藤尾，乃一篇之主旨。”** 全书贯穿的主题，是“**魂胆**”愈多，愈是祸根。

## 一、紫、藤尾、克莉奥帕特拉

!!! note "开篇"
    掩映着娇红的阳春三月，那酽酽的白昼，女子俨然是从春色中细绎出来的浓郁紫色之滴，趁着天地打扮的空隙，鲜艳欲滴地正待滴落下来。……**一旦循着这双眸子追溯而去，穷尽了它那带有魔力之境的所在，那也就是到了埋骨桃源、再也无从重返尘寰的那一天了。** ==可这并非只是一场梦境。==

!!! quote "“望着我，直到你死去的那一刻！”"
    糊朦胧而又浩渺无涯的梦境中，一颗璀璨的不祥之星，闪烁着紫色，朝眉睫间逼近过来，口中念念有词道：“望着我，直到你死去的那一刻！”
    
    女子身穿一袭紫色的和服。

!!! example "匕首之恋"
    “这不是和风细雨之恋，泪眼婆娑之恋，长吁短叹之恋，而是暴风雨之恋，千年历书中从来不曾记载过的狂风暴雨之恋，是锋利的匕首之恋。”小野说道。
    
    “锋利的匕首之恋，也是紫色。”
    
    “匕首之恋并非紫色，紫色之恋方为一柄匕首。”
    
    “你的意思是，爱情一旦所伤，就会流淌出紫色的血？”
    
    “我的意思是，爱情一经激怒，匕首便会闪出一道紫色的锋芒。”
    
    ----
    
    “那紫色，敢情让嫉妒给浸染得更浓烈了吧？”
    
    “紫色一经埃及赤日炎炎的烤炙，寒气逼人的匕首便会发出光亮来。”

    她就是这么个人，就是她在有求于你，也会随时抢白你的。……**正游走在诗的国度里的男子，突然间一脚踩空，跌落到了尘世凡界；一旦跌入尘世，他也便成了一名凡夫俗子而已。对手正在那高不可攀的山崖上俯视着自己。**

## 二、色相世界——小野

!!! note "甲野日记二则"
    见色者不见形，见形者不见质。
    
    小野是察看着色相而生存于世的一个人。
    
    生死因缘了无期，色相世界现狂痴。
    
    小野是栖居在色相世界里的一个人。

!!! quote "河底的荇藻"
    飘荡在幽暗河底的荇藻，自然不会知道白帆行驶的河岸边期日高照的情景。它忽而摆向这边，又忽而倒向那边，任由波浪的拨弄，只要时相顺从而不忤逆，倒也相安无事。……**唯有听命于命运的吩咐，“你就生长在这幽暗的地方吧！”于是便生长在了那幽暗的地方。**——小野便是这河底的荇藻。

!!! quote "这世界是个色相的世界"
    这世界是个色相的世界。形体不过是色相的残骸。光顾着琢磨残骸，却不解个中滋味和奥妙，就好比有人只会在那儿掏泥着酒器造型的敦方敦圆，却全然不懂得该拿泡沫直冒的美酒怎么办才好似的。==就算你把酒具琢磨得再透彻不过，也还是无法把它给喝下肚去，而酒不沾唇，酒味便会都跑光了的。== 光顾着注重形式的人，就好比抱了里面只盛满了道义的深不可测的酒器，逡巡在大街上似的。

!!! tip "坦塔拉斯"
    ...<span style="color:red">**每次透过那洞眼去窥视未来的时候，小野总觉得自己就跟这坦塔拉斯的干儿子似的**</span>，不仅如此，藤尾还时不时地不给你好脸色看……有时候呢，石榴石又会“啪”的一下燃烧起来，女子的身影便让这火焰裹挟着失去了踪迹；有时候呢，眼看着“博士”二字的色泽渐次褪去、剥落，化为一片黯然；再有的时候呢，这金表又会跟陨石似的，从遥远的天际坠下，砸了个粉碎。

## 三、甲野：一个琢磨不透的人

!!! quote "宇宙是个谜"
    宇宙是个谜。解谜的人都很随意。随意地解谜，随意地安心下来，这样的人真是有福气。……**所有的疑团，都得舍弃自身之后方才有望解开，只是，该如何舍弃自身，却成了个难题。去死？选择死，那也太无能了。**

!!! note "甲野的笑"
    难以捉摸的情绪波动，经由细如发丝的管道，好不容易从内心深处流淌而出，在世俗人间的白昼，灵光闪现般地留下了它的影子。……**甲野的笑，是那种淡淡的，与其说柔和，不如说是冷冷的笑。** 它在老实温顺的深处，在瞬息呈现，又瞬息消逝中，清晰地勾描着甲野的平生。

!!! abstract "父亲画像"
    可是，自己念叨着想要相聚重逢的这个人却已经死了，**活下来的，仅仅是他活的这双眼睛**。就是这仅有的一点儿还存活的东西，也都是纹丝不动的。

    ----
    
    入道无言客，出家有发僧。

## 四、道义与“第一义”

!!! question "失去与依托"
    自己的世界被分割成了两半，分割的世界一旦分头运作起来，便会产生痛苦的矛盾。……**就在小夜子与新桥车站相遇、碰撞的那一刻，她的世界便出现了第一道裂痕，这之后，裂痕将布满她的整个世界。** 小说便是从这一刻发轫、起始的。

!!! note "自尊之爱"
    爱的对象，那不过是一件玩具，一件神圣的玩具而已。……藤尾只准自己玩弄男子，不准男子玩弄自己，丝毫不允许有通融的余地。藤尾是爱情中的女王。
    
    **自尊之爱，俨若戴着消防兜帽在那儿吮饮甜酒似的，让人看着都觉得煞风景。……可将自尊之爱浸泡在爱情水中，就是浸泡上三天三夜，也丝毫不见有被浸泡酥软的迹象，始终坚硬如初。自尊之爱是一块冰糖。**

!!! quote "宗近的“诚恳踏实”"
    我能比你日子过得安生些，并不是因为没有学问的缘故，也不是因为不用功的问题，这都跟它们不相干。那是因为我有时还算诚恳踏实做人的缘故。……**只要你诚恳踏实地做人，那你就从一开始便会意识到自己确凿存在于天地之间的这一事实。** 所谓的诚恳踏实地做人，我跟你说，那便意味着一场严肃的角力，意味着击败对手……**一个人只要诚恳踏实地做人，不光他这样的人会得到救助，而且整个世界都会得到救助的。**

!!! quote "悲剧论"
    问题无数。是粟？是米？那是喜剧。是工？是商？同样也是喜剧。是这个女子呢？还是那个女子呢？那还是喜剧。……==剩下最后一个问题——是生？还是死？这才是悲剧。==

    十年便是三千六百天。从早到晚烦扰着一个普通人的身心的，都是些属于喜剧性的问题。三千六百天，就这样天天在上演着喜剧，终于把悲剧忘了个一干二净。……**浑然遗忘了死的人，活得真是奢华。载浮是生，载沉也是生。**

    ----
    
    由于道义观念的极度衰竭，正在那儿努力维持着社会，以满足众人对于生的欲求之际，悲剧却一下子发生了。于是，众人的眼睛便各自转向了自己的出发点，这才意识到，**从一开始起，死便是与生比邻而居的**。……意识到，重新拉起一道拦绳，乃是一件刻不容缓的大事。意识到，第二义以下的活动，都是那么的无益和无聊。于是，这才开始真正地领悟到了悲剧的伟大……

    > 两个月之后，甲野将这一节抄录了下来，寄给了远在伦敦的宗近。宗近在回信中这样写道：
    > 
    > 此地所盛行着，皆为喜剧。

## 五、女子群像：小夜子与系子

!!! note "小夜子的梦境"
    在这连贯通关东关西春天的二百里的铁路上，心里维系着一丝“唯有爱才是真诚的”心愿的小夜子，一路让火车震颤着，穿行在漫漫的长夜之中。**过去的五年，就恍若一场梦境……小夜子的梦境，要比她的生命来得分明。**

!!! quote "小野不识这幅画"
    小巧的耳朵，从鬓发的末端那儿优雅地钻了出来，脸颊与颈项相交接的地方，就跟着晕染似的摸出一道曲线，隐隐地延伸开去。**整个儿就是一幅很美的画儿。只可惜坐在她正对面的小野，浑然不识这画儿的美。** 诗人所钟爱的是那种感性的美。……要是小野能在这一瞬间捕捉住这幅美丽的画，那么，说不定他就会回过头去，就连脚下皮鞋的后跟也会因为转身过猛而陷进了地里，朝那流逝了的五年时光，那往昔过去，飞扑而去。

!!! note "系子：五指并拢的女子"
    系子似乎便是这么个指示目标时五根指头老是并拢在一起的女子。……指人时，纤细的手指，指尖若很瘦削的话，那么，很显然，感觉便会渐次聚集在指尖上，形成聚焦点。**藤尾的手指，俨然一根锐利的缝衣针，由嫣红的指甲间穿凿而出。** 见了这手指的人，一时间便会隐隐作痛起来。

    ----
    
    藤尾和系子，便在这间六席榻榻米的屋子里，展开了一场**五指对针尖**的战争。所有的对话都是一场战争。女人之间的对话，就更是一场战争了。

## 六、京都·写生美文

!!! quote "三十六峰与友禅染"
    此时，上京和下京，濡湿在淅淅沥沥的细雨里，三十六峰青翠深处，唯有溶入了友禅染艳红的河流，带着声响，灌注进菜花丛中。“你在河上游，我在河下游……”有人哼着谣曲，在门口漂洗芹菜，解下遮掩住了眉头的手巾，一抬眼便能望见那呈现为“大”字图案的篝火。……**只有春雨，一如古昔时代的模样。**

!!! quote "文明之诗的代价"
    文明之诗，由钻石制作而成，由紫色制作而成，由玫瑰的芬芳、葡萄酒、琥珀杯制作而成。……有时则现身于女子和服的织锦腰带，腰带上不嫌繁缛地点缀着野径、天空、月亮以及秋日花卉盛开的原野。**文明之诗就现身于金钱之中。** 小野须得去赚取金钱，方能保全他诗人的本分。

    俗谚云：作诗不如耕地。……世界上既不会有像诗人这样赚不了钱的买卖，自然也不会有像诗人这样亟需赚钱的买卖。

## 七、砸碎那块怀表

!!! danger "“二十五分。”"
    紫色浓艳的缎子蝴蝶结上聚满了怒气，钻出车篷之际飘然打了个寒战的克莉奥佩特拉，突然冲进了玄关。
    
    “二十五分。”
    
    就在宗近话音还未来得及落下的当儿，**愤怒的化身，犹如蒙受了羞辱的女王似的，挺立在了书斋的正中央。**

!!! example "怀表在大理石炉角上碎裂了"
    藤尾露出一大截白皙的胳膊，“嗖”地伸过手去。那块表，便切切实实地落在了宗近那漆黑的掌心里。宗近朝暖炉那边跨过一大步，只听得“嗨！”的一声，漆黑的拳头便应声扬了起来。怀表在大理石炉角上碎裂了。
    
    “藤尾，我绝不是为了想要这块怀表才一时异想天开着来搅你的局的。……只有把它给砸了，你们也许才会明白我的心意。这也是‘第一义’活动的一部分。你说是不是，甲野？”
    
    “是的。”
    
    站在那儿的藤尾不禁愕然，脸上的肌肉一下子凝固住了。手和脚都变得僵硬了起来。**俨然一具失去了重心的石像，藤尾蹬翻椅子，跌倒在地板上。**

## 八、虞美人草

!!! abstract "终章·两扇银白屏风"
    两扇折叠的银白屏风，倒了个儿，竖在那儿。六尺屏风以清澄月色打底，上面贸贸然用铜绿色纷乱地勾描出柔婉的花茎，又层层叠叠地勾描出不规则的锯齿状叶片。……花瓣画得很淡，只要用手指轻弹花茎，便会翩然凋落。……既有红色，也有紫色。**所有的花瓣都勾描得让人恍然觉得，它们生自银白，绽放于银白，最终又凋落于银白——这花卉便是虞美人草了。** 画的落款是“抱一”。

    屏风背后放着藤尾用惯了的拼花木小书桌。……书桌上供着一盏素烧陶器，里面灌了油，虽是白昼，也点燃着一根灯芯。灯芯是新的。

!!! note "尾声"
    即便如此，甲野仍选择留下照料母亲；小野在银屏风前、线香将燃尽的一刻，手捂苍白的额头走了进来。宗近远赴伦敦，来信只有一句：

    > 此地所盛行着，皆为喜剧。

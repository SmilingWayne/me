# 洛阳伽蓝记

杨闳之记录洛阳的佛寺。待补充。先放一个我的书评。

## 浮屠塔断了几层

与伽蓝寺的相遇，是在长春西站。东北十月的风已经吹得我有些不适，遂躲至车站等待南下的列车。长假但人流不多，我打开了杨闳之的这本《洛阳伽蓝记》。分明离发车还有一个半小时，我却陷死在了永宁寺的大火中。

读之前我很少浏览过北魏的历史，放下书，我却越发难以忘记这串被戏称为中国历史”垃圾时间“的朝代更替和死人名字。从迁都到易服，从马背到城阙，从拓跋氏的征服到孝文帝的汉化，北魏的凄风血雨无法遮掩游牧民族的成长。胡太后鸩杀孝明帝，尔朱荣屠戮北魏臣，数不尽的伽蓝寺再难瞧一眼汉月；孝庄帝诱杀尔朱荣，尔朱兆再破洛阳城，河阴的兵刃从来都裹挟着胡尘。

杨闳之写洛阳佛寺兴废，是在武定五年（547），距离永宁寺的火已经过去了13年。全书五卷，城内，和东南西北四方位，以佛寺名与地理位置这种特色方式，标定了洛阳城的坐标。至今读之，掩卷叹息不止。唐人写“南朝四百八十寺，多少楼台烟雨中”，北人不语。北人描述的方式就是这本《洛阳伽蓝记》。

前些日子跟同事闲聊，同事问我“有没有信仰”，同行者皆惊讶，颇感错愕于这个突如其来的问题，一番谈笑后，我发现自己竟是一行4人中唯一不是党员的。我开玩笑说，大家都是有信仰的人，我觉悟不够高，只适合醉吟风月，不适合艰苦奋斗叭！

话说出口我突然就想到了这本书，我好像明白了一个我百思不得解的问题，为什么那个时代，无论是篡位的权臣、称制的太后，奢侈的富商，外来的信使，都对西南边传来的佛法顶礼膜拜，所到之处，皆奉释迦菩提为尊，人来往地，具可见精舍僧房，好像一阵风刮来，人的思维便被佛法夺了舍——仿若一种魔力。

那是因为「真正处在历史垃圾时间」的人们，必须要找到信仰。所谓「人民有信仰，国家有力量」，说的是一个意思——人需要一个解释，“为什么活着”——这个解释可以，甚至应该是虚妄的，自己骗自己的。管什么谁信谁不信，反正我得信。

谁能在见惯了如此频繁的城郭崩坏、法纪松弛、国政混乱、王朝更迭后，还保持着自己的信仰呢？今朝的统治者，那些汉化的胡人，短短几日就作了刀下的亡魂，国王的出逃，臣子的背叛，宦官的攀附，共同被挤兑在一个烧杯里加热煮沸，没有人在乎百姓的生死，歌舞升平时，谁又知道下一场大火在哪里点燃？

于是，享乐吧，疯癫吧，抓紧眼前事，珍惜眼前人。贪婪地吸吮当下的歪瓜裂枣——困厄的君主死前难得一口蜜水，百姓肚子里又哪里能找到一口的肉汤呢？这里的秩序是崩坏的，未来是不断循环的历史，历史是可以预测的未来。这可真是令人绝望，令人精神失常。

而佛法给人心的抚慰便在于此。它不教你看历史，它抽象出一种轮回、一种苦集灭道，一种自我保护。我深信佛以及佛的术语、意识，正是在这段乱世的烧煅下，被浇铸到汉文化的铅字里，那些我们常说的字眼，竟纷纷可追溯到那些佛思之中：

“金刚”、“三世”、“报应”、“世界”、“相好”、“菩萨”、“浮图” ...

多少伽蓝寺被烧毁、重建、再烧毁，多少描述伽蓝寺的文字被传抄、烧毁、再传抄、再烧毁，终至散佚？

我总是想，南北朝之所以常让初读历史的国人奇怪与难以下咽，一个原因可能在此。我们看到的是上承三国，下启隋唐，一种风流潇洒，一种青眼白眼，一种广陵散，一种兰亭序。**我们见到的，是一种「文艺化」了的历史** 。翻翻书，义务教育的课本塑造了一套颇有秩序的历史叙事，有人编排好了一套框架，唐尧虞舜，秦皇汉武；韩赵魏楚燕齐，梁唐晋汉周，宋齐梁陈，唐宋元明清，一字排开，整整齐齐——但是却少有把探针打入毛细血管，去化验朝代夹缝或王朝更迭的尖刺时间里，一座城市、一群僧尼、一群歌女的血液成分：他们经历了什么，又看到了什么，他们在为什么哭泣，或者他们根本就来不及哭泣呢？他们在为什么杀戮，或者他们根本就来不及搞懂他们在为何而杀戮呢？

而现在，**是时候看看「历史化」了的文艺了**。私以为这本《洛阳伽蓝记》，是一本非常符合这个标准的书。伽蓝寺的火，以及这团火紧随着带来的熊熊燃烧之感，敦促着我走到一千五百年前的洛阳城，看沙门的繁荣，看佛法的无边，看一片虔诚下，那绝望且无处寻觅的信仰。

是以为记。

# 西方象征主义

## 概览

<span style="color:#1E90FF;font-weight:bold">19世纪70年代，在法国</span>崛起的象征主义，是以<span style="color:#32CD32;font-weight:bold">魏尔伦</span>和<span style="color:#32CD32;font-weight:bold">兰波</span>这对放浪形骸而又才华横溢的诗友为代表的。

> 十九世纪巴黎青年才子们把文艺沙龙<u>从十七世纪的豪华府邸移到了塞纳河畔或蒙马特山脚的咖啡馆里</u>，故作风雅的谈吐变成了狂放不羁的舌战，闪光的思想、新奇的诗句，便在这独特的氛围里孕育滋生。

兰波以《元音》一诗与<span style="color:#32CD32;font-weight:bold">波德莱尔</span>相应和，对<span style="color:orange;font-weight:bold">元音字母做了色彩的辨析</span>，为通感论提供了略带稚气又值得玩味的样板。1871年又与波德莱尔的“洞观者” (`Le visionnaire`) 相对应地提出了诗人应成为通灵者 (`Le voyant`)的主张，发展了<span style="color:orange;font-weight:bold">通感</span>的理论。

曾经作为浪漫派与帕尔纳斯诗派追随者的魏尔伦，以一批清新流畅的诗蜚声文坛。<span style="color:orange;font-weight:bold">他主张艺术的“真诚”，强调“至高无上的内在音乐美”，追求模糊与精确的结合，从而与前两者分道扬镳</span>。

80年代是法国象征主义的鼎盛时期，<span style="color:#32CD32;font-weight:bold">马拉美</span>被称为“象征主义的象征”。围绕在罗马街5号寓所形成了“周二聚会”：瓦雷里、纪德、拉弗格、亨利·雷尼耶、古尔蒙。

1886年9月18日，原籍希腊的法国诗人、《象征主义者》的主编<span style="color:#32CD32;font-weight:bold">莫雷亚斯</span>在《费加罗报》上发表了《象征主义宣言》：

> “我们曾建议用象征主义作为目前这种具有创造精神的新的倾向的命名，只有这个名称能恰当的表明其特点。”

象征主义既反对已成强弩之末的浪漫主义的浮夸热情，也不满于帕尔纳斯诗派的雕琢空泛，更针对主张描绘忠诚的描绘现实的自然主义表达反对 …… 他们在重新思考把握文学的特征，主观的抒情、客观的再现、纯形式的追求，都不能使他们感到满足。<span style="color:orange;font-weight:bold">他们努力寻找主客观之间的契合点，努力寻求新的艺术表现途径</span>。

1890年代，《颓废者和象征主义者》：

> 颓废者代表一批<span style="color:orange;font-weight:bold">对自然主义非常反感</span>的年轻作家，他们<span style="color:orange;font-weight:bold">寻求艺术的革新</span>，以敏感而响亮的诗歌<span style="color:orange;font-weight:bold">取代帕尔纳斯派呆板单调的诗律</span>……人们能感到有生命的颤动掠过。为了表现感觉和意念，他们扫除了旧文学中的一切空话 …… 

<span style="color:orange;font-weight:bold">象征主义和颓废主义是难分难解的</span>。它们产生于共同的时代背景，具有共同的情感特征——苦闷、彷徨、愤懑……也都以否定传统为己任，既反对当时的社会秩序，也反对现有的艺术法则。当然我们也应指出，其中包含强烈的反叛精神和执着的艺术追求，不能简单地把颓废主义视为没落、衰朽和悲观的同义语。象征主义也应作如是观。

<span style="color:orange;font-weight:bold">象征主义理论创作的基石是“通感”</span>。得益于<span style="color:#32CD32;font-weight:bold">叔本华</span>的**唯意志论**和<span style="color:#32CD32;font-weight:bold">柏格森</span>的 **“直觉论”** ，也受到当时风行的 **“唯灵论”** 的影响。无疑，它应该被划入唯心主义的范畴。

<span style="color:orange;font-weight:bold">象征主义认为，在可感的客观世界深处，隐藏着一个更为真实、真正永恒的世界</span>。兰波把它形容为“未知”。<span style="color:orange;font-weight:bold">人们只有凭本能的直觉才能领悟，而艺术地传达出这种秘密，便是诗人的最高任务</span>。

<span style="color:orange;font-weight:bold">人之所以能领悟那神秘的未知，是因为人的内心与外部客观世界之间存在着通感。人的各种感觉之间也是相通的</span>，而诗人的与众不同之处在于<u>体验过各种广泛长期的有意识的错位，情爱、痛苦、疯狂，从而获得异于常人的感知力</u>，由此才能深入地把握光怪陆离的自然和人生，创造出独特艺术。可以说，<span style="color:orange;font-weight:bold">象征主义较系统地把非理性主义引入了文学创作的领域</span>。

由此，象征主义作品的显著特征就是朦胧美和神秘色彩。诗句晓畅自然，富于乐感，然而<span style="color:orange;font-weight:bold">其中多含暗示、象征和暗喻</span>。

> “直陈其事、直呼其名，这就等于取消了诗歌四分之三的乐趣。这种趣味原是要一点一点去领会的”。
>
> ...
>
> 必须通过“暗示”、强调 “充分发挥构成象征的这种神秘作用”，穿过象征的森林，才能领略诗歌的真谛。
> —— <span style="color:#32CD32;font-weight:bold">马拉美</span>

由于象征主义丰富的内涵和多义性，给读者带来了极大的联想自由和审美乐趣。又由于它难以理解，使它失去了许多缺乏耐心的读者。曲高和寡，致使它未能为社会大多数所接受。

<span style="color:#1E90FF;font-weight:bold">90年代后期</span>，象征主义在法国日趋衰落时，影响却越过边境，传向世界各地：

1. <span style="color:#32CD32;font-weight:bold">格奥尔格</span>把它引入了德国。
2. <span style="color:#32CD32;font-weight:bold">里尔克</span>把它引进了奥地利。
3. <span style="color:#32CD32;font-weight:bold">勃兰兑斯</span>把它引进了丹麦，
4. <span style="color:#32CD32;font-weight:bold">亚迪</span>把它引进了匈牙利，
5. <span style="color:#32CD32;font-weight:bold">巴尔蒙特</span>把它引进了俄罗斯，
6. <span style="color:#32CD32;font-weight:bold">达里奥</span>把它引入了西班牙语创作。

<span style="color:#1E90FF;font-weight:bold">二十世纪二十年代</span>，象征主义出现了第二次高潮，通常称为后象征主义。<span style="color:#32CD32;font-weight:bold">法国的瓦雷里</span>继续着马拉美"纯诗"的思路，追求音乐性的同时增加了哲理的思考。<span style="color:#32CD32;font-weight:bold">美国的庞德</span>举起了意象主义的大旗，领导了英美的意象派大军。<span style="color:#32CD32;font-weight:bold">俄国的勃洛克</span>运用象征派的艺术，讴歌苏维埃革命事业。<span style="color:#32CD32;font-weight:bold">美国的艾略特</span>则兼收并蓄，融入了宗教意识。

第一次世界大战给西方人带来了前所未有的灵魂战栗，<u>世界的无秩序、无规律、无意义成为西方人的共同感知</u>。诗人们便==各显神通地在艺术中重建这个混乱的世界，希望以象征的体系来使混乱的世界秩序化==……在这里，处处都渗透着惶恐和悲观的情调……

<span style="color:#1E90FF;font-weight:bold">1910年代，意象主义在英国崛起</span>。主张面对生活，面向现代化工业城市的丑恶，==主张客观性，强调依靠直觉去捕捉生活中的意象，书写人们对具体事物的色、形、味、声等各种特质的直接接触==，常喜欢使用叠加的手法，把一个概念叠加在另一个概念之上。而意象就是一刹那间思想和情感的复合体。

## 主张、理论

《论泰奥菲尔·戈蒂埃》，波德莱尔，「？」
:   <span style="color:orange;font-weight:bold">诗的本质不过是人类对一种最高的美的向往</span>。这种本质表现在热情之中，表现在对灵魂的占据之中，是完全独立于激情的，是**一种心灵的迷醉**，同时也完全独立于真实，是理性的材料……

    浪漫主义热烈的倾吐感情（“从心里出来的诗！”）。这就把全权给了激情，似乎激情是万无一失的……心里有激情、有忠诚、有罪恶，<span style="color:orange;font-weight:bold">但唯有想象里才有诗</span>。

    新的灵敏感并不绝对有利于诗歌创作。<span style="color:orange;font-weight:bold">想象力的敏感则是另一种性质</span>，他知道如何选择、判断、比较。既迅速又自发。这种敏感被称作趣味，<span style="color:orange;font-weight:bold">在诗歌的方面，我们正是从这里汲取了避恶求善的力量</span>。

    戈蒂埃的诗神居住在一个更为缥缈的世界中，他很少关心，关心的太少了 ...

《维克多·雨果》，波德莱尔，「？」
:   <span style="color:orange;font-weight:bold">道德并不作为目的进入这种艺术(诗歌)</span>，它介入其中并与之混合，如同融进生活本身之中。诗人因其丰富而饱满的天性，成为**不自愿的道德家**。

    描写现存之物，诗人就降格了，流入了教师之列；<span style="color:orange;font-weight:bold">叙述可能之物，他才是忠于职守</span>；他是一个集体的灵魂，询问、哭泣、希望，有时猜测。

《致班维尔》，兰波，1870，时作者15岁
:   两年或一年内，我将来巴黎成为一名帕尔纳斯派诗人……以下是我的三首诗……亲爱的导师，请帮我一把……

《致保尔·德梅尼》，兰波，1871
:   想当诗人，==首先需要研究关于他自身的全部知识，寻找其灵魂并加以审视、体察、探究==。一旦认识了自己的灵魂，就去耕耘它。

    <span style="color:orange;font-weight:bold">我认为诗人应该是一个通灵者，使自己成为一个通灵者</span>。

    必须<span style="color:orange;font-weight:bold">使各种感觉经历长期、广泛的、有意识的错位，各种形式的情爱、痛苦和疯狂</span>，诗人才能成为一个通灵者。他寻找自我，并为保存自己的精华而饮尽毒药。在难以形容的折磨中，他需要坚定的信仰与超人的力量。他与众不同，将成为伟大的病夫、罪犯、伟大的诅咒者，因为他达到了未知……
    
    <span style="color:orange;font-weight:bold">诗人是真正的盗火者</span>。

    ... 

    第一批和第二批浪漫主义者都是通灵者……只不过有的人偶然，有的人过于固执，有的人止步于旧的形式。

《谈文学运动》，马拉美，1891
:   每一个诗人都在自己的角落里，用自己的笛子吹奏着自己喜爱的调子。

    <span style="color:#1E90FF;font-weight:bold">在一个不稳定、不统一的社会中，不可能创造出固定的、统一的艺术。社会组织的不健全使人们感到焦虑不安，产生了对个性发展的严酷要求。当前的文学运动正是它的直接反应</span>。

    **直接原因是人们理解到旧的诗歌形式不是绝对的、唯一的和不可变动的**，它只不过是写做好诗的一种方法而已……

    并没有所谓散文，只有字母表以及不同程度的简练的诗和不同程度的冗长的诗。**只要你追求风格，你就是在琢磨诗句**。

    帕尔纳斯诗派喜欢严谨的形式美 …… 但是后进者的创作意图并不是要取消正统诗体，**他们只求在诗歌中放进更多的空气，在宏伟的诗句间创造一种流动的、变化的东西**，而这正是前一时期的诗歌所缺少的。

    ...

    <span style="color:orange;font-weight:bold">在诗歌中只能有隐喻的存在</span>，暗示才是我们的理想，一点一滴地去复活一件东西，展示出一种精神状态……<span style="color:orange;font-weight:bold">必须充分发挥构成想象的这种神秘作用</span>……

    在诗歌中应该永远存在着难解之谜。文学的目的在于召唤事物，而不能有其他目的。

    我讨厌流派，反对一切应用在文学上的传授教导。文学完全是一个人的事业……

《象征主义宣言》，莫雷亚斯，1886
:   象征主义诗歌是“教导、朗读技巧、不真实的感受力和客观的描述”的敌人。

    象征主义探索的是：<span style="color:orange;font-weight:bold">赋予思想一种敏感的形式。但这形式并非探索的目的</span>，它有助于表达思想，又从属于思想……象征主义的<u>基本特征就在于它从来不深入到思想观念的本质</u>……赋予感受力的表象（自然景色、人类行为等），是要体现它们与最初的思想之间隐秘的亲缘关系。

    象征派需要一种原始典范以及复合的文笔： 
    
    纯净的==未被污染==的词，==词义充实==与==词义浮华==交替出现，有意识的==同义叠用==，神奇的==省略==，令人生出悬念的==错格==，一切大胆的与多种形式的==转喻==。总之，**这是一种独创的、现代化的优美语言**。

《纯诗》，瓦雷里，1920
:   任何一部文学作品、艺术作品，都有一些独特的方面或成分。它们的特点，姑且称为**诗情**。每当话语中表现出有些偏离，最直接的，也就是最没实体感的表达思想的言辞时，我们就感到有扩大这个特殊领域的可能性……

    是否可以用那些没有实体感的言辞来创造一副完整的作品呢？或者说，**我们能否创作一部完全排除非诗情成分**的作品呢？

    我们用**纯诗**或绝对的诗来描述或许更准确。由于词与词的关系、共鸣效果，人们必须进行某种探索，而它**首先要求研究受语言支配的整个感觉领域**……

    ...

    **诗人的任务就是在语言**，这种统计结构的产物，这种纯粹供实践之用的工具中，<span style="color:orange;font-weight:bold">找到某些手段，创造一种没有实践意义的真实……诗人的使命就是创造与实际制度绝对无关的一个世界，一种秩序，一种关系体系</span>。

    ... 「比较了诗人和作曲家的创作」

    <span style="color:orange;font-weight:bold">诗人正是要从语言这个杂乱无章的大杂烩中找到艺术的物像——产生诗情的语言结构</span>……诗人从这个杂乱无章的混合体中吸取的成分，是个人努力的结果。他用最平常的材料创造出一种<u>虚构的理想秩序</u>。

    纯诗的理想是一种不可思议的典范思想，是诗人的趋向、努力和希望的绝对境界的思想。

《论诗》，瓦雷里，「？」
:   我始终赞成这些观点：避开眼前的事物，从象征走向象征，用象征来激起某种特殊的情感。

《论文学技巧》，瓦雷里，「？」
:   艺术家们已经忘记了寓意之美，而寓意之美正如波德莱尔所写的那样，是基本的美学形式。

    诗人要尽可能避免将自由联想的缪斯赐予他的一切都泼在纸上。相反，<span style="color:orange;font-weight:bold">他对于想象、感觉、虚幻和构筑的一切，都需要进行压缩、筛选、斟酌，置于形式之中。尽可能凝练，以力量而非长度取胜</span>。

《诗歌的象征主义》，叶芝，1900
:   当声音、颜色、形式之间的融为一体，形成一种相互间和谐统一的美妙关系时，它们似乎变成了同一种声音、颜色和形式，并激发出同一种感情.

    ……
    
    艺术越是完美，它激起的感情力量 ... 也就越会强有力.

    **韵律的目的在于延续沉思的时刻，那是创造的时刻。用迷人的单调使我们安睡，又用变化让我们保持清醒**……韵律只是一种变得更轻微的钟表的滴答声，使人必须倾听，而又富于变化，使人不至于忘了它或者听得不耐烦。

> 意象主义者们承认他们是后印象主义和未来主义的同时代人。他们没有发表过一个宣言，不是一个革新的流派。他们努力方向是要遵循最优秀的传统写法
>

《论文选》，庞德，「？」
:   1921年，我们认为三项原则是一致的：
    
    - 对于所写之物，不论是主观的或客观的，要用**直接处理的方法**。
    - 绝不使用任何对表达没有作用的字。
    - **关于韵律，按照富有音乐性的词句的先后关联，而不是按照一架节拍器的节拍来写诗**。

    ... 

    一个意象是在瞬息间呈现出的一个理性和感情的复合体。这种复合体突然呈现给人的是一种解放的感觉，不受时空约束的自由的感觉，一种我们在面对伟大的艺术品时经常受到的突然长大了的感觉……
    
    <span style="color:orange;font-weight:bold">一个人一生中能描述一个意象，要比能写出成篇累牍的作品好</span>。

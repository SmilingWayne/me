# 图书馆：不落幕的智慧盛宴

在永远敞开的大门后面，任何长矛都无法保卫即将崩塌的王座。没有侍从们的阿谀，没有谄媚者的伺候，这是属于民众的宫殿。 —— 献给波士顿新市立图书馆。

---

<span style="color:orange;font-weight:bold">最早的图书馆诞生于5000年前的新月沃地。古老的美索不达米亚通常用芦苇笔在软泥板上刻写文字</span>。

当遭遇外族侵略的时候，古代城市的图书馆和档案馆通常会被烧毁，里面的泥版文书则会被征服者掠走。由于它不能被烧毁，在西南亚干旱的气候中得以保存下来。公元前1650年，埃布拉被随风而来的风沙掩埋，成为了废墟。直到20世纪70年代，考古学家才发现了有楔形文字的泥版文书。

埃及人使用莎草纸书写。和泥板相比，莎草纸更加轻便，而且是埃及几乎独有的植物。然而，莎草纸非常容易腐烂，因此古代留存下来的文本非常稀少。相比之下，新月沃土的黄沙之下已经出土了40多万块泥版文书。

希腊是第一个建立<span style="color:orange;font-weight:bold">公共图书馆</span>的国家。公元前500年左右，雅典和萨摩斯已经拥有了公共图书馆。但当时绝大多数人都不识字，所以图书馆只能为少数公民提供服务。然而，学者们通常有更大的胃口。他们喜欢精美的书卷和藏书室，于是有了更多的私人图书馆。柏拉图、希罗多德等都有自己的私人图书馆。

<span style="color:orange;font-weight:bold">亚里士多德的图书馆</span>是最著名的，他的学生和同行都可以进去读书。不过后来，据说他的很多馆藏书籍被罗马人或亚历山大人带走了，流传到了君士坦丁堡。

马其顿国王亚历山大大帝在一生的征服中，占领了希腊和当时已知的大部分世界。但是他的军队同样带来了大型图书馆的毁坏。3世纪的一卷波斯手稿记载，**亚历山大给波斯带来了严酷的战争和毁灭。洗劫波斯波利斯的过程中，古都典藏丰富的图书馆也成了牺牲品。据说他的军队冲进“摆满用金墨在牛皮上写成的圣书”的房间，然后“把书籍付之一炬”**。

公元前300年，托勒密一世创立了<span style="color:orange;font-weight:bold">亚历山大图书馆</span>。它迅速成为了当时世界上拥有最大藏书量的图书馆。历史上，这座图书馆经历了凯撒军队的大火，也经历了多次地震的摧残。战争、当地基督教的反异端暴乱，也使得亚历山大城里的各个图书馆损失惨重。自然灾害、图书管理员的盗窃和其他原因导致馆藏持续下降。到了公元4世纪，这座建筑和藏书都已经不复存在了。

现在埃塞俄比亚所在的地区，公元前5世纪左右叫<span style="color:orange;font-weight:bold">阿克苏姆王国</span>。1世纪开始，阿克苏姆成为欧亚非的贸易中心，并且从部落文明上升为军事实力雄厚的帝国。后来，他的船队和商船从红海南岸出发，抵达罗马、波斯，成为世界上有影响力的四大帝国之一。

> 在这里，埃及的<u>科普特僧侣</u>翻译了大量的《圣经》译本，还抄写了基督教诞生以前的《以诺书》。他们的统治者经常使用希腊语，因此习惯把大量的文献储存在图书馆里，并翻译成各种语言。
>
> 根据当地人的民谣，希伯来人的约柜就藏在阿克苏姆的教堂里，由牧师们守护。这是按照上帝的指示制造的，里面装着一些神圣的经文，其中包括上帝交给摩西的“十诫”石板书。

罗马共和国和后来的罗马帝国承接了古希腊文明。公元1世纪到4世纪，<span style="color:orange;font-weight:bold">罗马人在当时疆域内建立了图书馆</span>，拥有最好的拉丁语和希腊语书籍。为了保护所谓的希腊传统文化，古罗马的图书馆<u>都建成神庙的形式</u>，把拉丁文和希腊文书籍分开储藏。房间与房间之间有屋顶的露台，读者和学者可以在屋顶的遮蔽下看书和聊天。<u>甚至一些图书馆还设置在公共浴池内，成了当时富人们奢华生活的标志</u>。古罗马人就这样长大，热爱书籍和文学，热爱生活。

公元6世纪，<span style="color:orange;font-weight:bold">罗马帝国的灭亡使西方的学术文化陷入黑暗之中。教会取得了全部的权力和影响力</span>。这期间，图书馆和抄写室的抄写员顶着外界知识萧条的压力，空前勤劳地工作着。他们抄写旧手稿，也抄写新书，为以后的收藏家们提供资源。此时，从大不列颠到黑海，分布广泛的抄写室意义重大。其一就是<u>书籍的插图艺术得到了极大的发展。书本从单面书写的莎草本逐渐转变为两面书写的羊皮书，新的装帧艺术、书法和设计逐渐产生</u>。

<span style="color:orange;font-weight:bold">古罗马人发明了书籍的侧装订形式</span>，将整卷书进行折叠，使阅读和储藏变得更方便。折叠好的书卷被切成纸张或者书页，并沿着一边捆绑整齐。装订好的内页外面用硬书皮保护。拉丁文中的 `codex` 就是**木块**的意思。后来用来形容「手抄本」。

公元6世纪的<u>本笃会</u>是意大利天主教教士圣本笃的追随者。他们在当时图书馆和书籍方面的影响力最大。他们的会规为修道会制定了职责和规范，建议修士们要适度对待所有的食物、饮食、时、洗礼和斋戒，并且每天阅读。他们的会规要求修道院的每一个修士手中至少要有一本书，同时告诫修士们不可虚度光阴，合理时间进行体力劳动和虔诚的阅读。一些本笃会的修士不仅每天坚持阅读，还坚持写作。他们被雇佣为抄写员，或者抄写书籍，或是把希腊文作品翻译成拉丁文。因此，<u>本笃会的抄写室是中世纪书籍的最大产地</u>。

与此同时，<u>天主教会的影响力进入修道院。他们把图书馆变成教会的公共财产，使得书本可以在修道院之间自由流通</u>，并且互相借书抄写的行为也得以发生了。可以用自己的书籍换取其他修道院的书籍。再到后来，知识阶层通晓拉丁文后，人们把拉丁文翻译成各种熟悉的地方地域的语言，比如西班牙语、法语、英语和德语。比如查理曼大帝（法兰克国王）在征服西欧后，倡导人们把基督教教义和祈祷书翻译成大量语言，并出品了各种年鉴。

随着教会势力的强化，出现了许多制作精美的书籍，包括镶嵌有象牙、金属、金箔的精装书籍。通常这些都是给封建贵族和教会高层们预定的，是封地领主向君王或君王之间互赠的礼物。

在中国焚书坑儒以后，严厉的知识分子正统论一直沿袭了下来。当儒家正统与迅速发展的佛教发生冲突时，汉朝政府就规定不得私自刊印佛教书籍。在当时，重要的佛教典籍都是在寺院里抄写的。在遭到迫害的年代，这种工作都是秘密进行的。当然了，也有一些信奉儒教的中国皇帝对佛老和道教采取了开明的态度。公元7世纪至10世纪之后，私人藏书风气盛行。有些藏书家向年轻人们开放藏书，帮助他们通过科举。

<span style="color:orange;font-weight:bold">莫高窟的藏经洞</span>里有近500座寺庙，50万平方英尺的宗教壁画，15000册纸质书。这座洞窟于公元11世纪被封，可能是为了防止入侵者毁坏，也可能是因为原著在重印后被废弃了。

15世纪，永乐大典开始编撰，集齐了11000册图书的大百科全书《永乐大典》面世。三个世纪后，清朝皇帝组织完成了一部36000册图书的大百科全书——四库全书。

统治的西班牙至少有70座图书馆，最大的一座位于科尔多瓦，是当时欧洲的第二大城市，仅次于君士坦丁堡。穆斯林的著作中，欧洲读者最感兴趣的是天文学、星象学和宇宙学。穆斯林们先进的航海仪器、医学和数学著作也受到欧洲人的推崇。从俄罗斯南部到西西里和西班牙，三种信仰的学者（基督教、伊斯兰教和犹太教）在图书馆里开展了紧密的合作。他们被统称为圣书的子民：他们的宗教也是由书籍引领的。基督教和犹太教信奉圣经，伊斯兰教同时信奉圣经和古兰经。

十字军东征在公元11世纪和13世纪期间，结束了三教和平共存、共同学习研究的局面。基督教军队入侵并占领了圣地，学者们公用的图书馆和书籍也在战争和宗教迫害之下遭到破坏或者焚烧。

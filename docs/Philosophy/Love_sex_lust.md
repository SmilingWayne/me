# 情爱论

苏联作家瓦西列夫（В. А. Василев）的情爱论著，中译本据称有相当篇幅的删节。原书读来不算抓人，笔记亦偏潦草；此处仅就摘录文本作结构化梳理。

## 爱情的本质

!!! question "柏拉图式的爱情是否存在？"

    人们怀疑是否存在这样一种柏拉图式的爱情：一个女人钟情于一个男子，或一个男子钟情于一个女人，然而他们之间没有任何身体的、性的接触。由此引出两个问题：

    - 究竟有没有<u>不产生在性欲基础之上</u>的男女之间的爱情？
    - 一个人在没有尝到禁果、即发生性行为之前，能不能体验到爱情？

**爱情的基础**总是相互的好感、彼此中意，这适用于作为肉体、精神、遗传和文化之整体的任何一个人。但对异性的认识总是主观的，它同时取决于产生爱的激情以及各种社会因素。

## 男人和女人

### 敌视女性的思想谱系

!!! note "笼罩在永世的夏娃身上的诅咒"

    一部贯穿千年的压迫史：

    - **古希腊罗马**：富裕奴隶主的妻子通常足不出户，几乎被监禁在丈夫家里；雅典妇女习惯于对丈夫唯命是从。歧视与诅咒延续至罗马帝国。
    - **基督教**：道德观念充满神秘主义色彩与反女权精神，把妻子的奴隶地位、对丈夫的依附说成合乎教规的神圣之物。
    - **中世纪**：僧侣哲学加深歧视，贞操被郑重宣布为最高美德，同妇女发生性关系则是最大罪过。阿奎那要人牢记亚里士多德的真言：「自然界总是力求创造男人，只在力不从心或偶然的场合才造出女人。」
    - **伊斯兰教**：同样歧视妇女。《古兰经》颂扬男子、反对男女平等，要求妇女把面孔遮挡起来，不被阳光直射。
    - **文艺复兴与宗教改革**：缓和了屈辱地位，但传统夫权仍被保留。资产阶级革命最伟大的预言家们（包括卢梭）也认为妇女是价值不大的个人，其最高品质是温顺，永远属于男子或男子的见解。

#### 哲学家论女性本质

| 哲学家     | 核心观点                                                                                                                                                             |
| :--------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **霍伦**   | 培养女子的唯一目的就是养育下一代英雄人物，他以一种独裁者的倨傲看待女性。                                                                                             |
| **叔本华** | 只有性欲冲动使理性变得迷惘时，男子才会觉得体格矮小、窄肩、宽臀的女性美——女性的全部美貌就在于一种性欲。他为节欲禁欲辩护，认为亲密感情是灵魂玩弄的狡黠骗局，主张遁入涅槃。 |
| **尼采**   | 与叔本华不同，却依然狂热仇视妇女。他不蔑视两性的肉体结合，反鼓吹肉欲方面的暴力；为超人理想应当不停生孩子。性奇迹剧中男子通常是胜者，妇女不过是母鹅。                     |
| **维宁格** | 男子是精神生物，妇女纯粹是肉体生物；妇女本身即性欲本身，男子首先创立纯精神领域，妇女却只关心性生活。                                                                   |

### 两性的心理差异

!!! note "阻力最小原则"

    两性的心理差别早在儿童时期就显露出来：男子倾向于学习榜样，女子则选择符合她们天赋的女性榜样。在一个新个性形成的过程中，起作用的总是**阻力最小原则**，即用最小的气力去掌握这种或那种社会角色。

## 疯狂和理智

### 理性的规定

| 哲学家       | 对「理性」的规定                                                       |
| :----------- | :--------------------------------------------------------------------- |
| **霍尔巴赫** | 借助经验、论断和思考而发生变异的我们的本性。                           |
| **康德**     | 抽象思维能力，是智力活动的等级。                                       |
| **黑格尔**   | 纯粹思维的第三级、也就是最高级，力求了解事物本质，揭示共同的基础。     |

!!! abstract "瓦西列夫的界定"

    理性是这样一种形式的思维：这种形式恰如其分地、纯净无瑕地实现并揭示思维的普遍辩证本质，以及它内在创造的性质。

### 爱情中的非理性

!!! quote "醉汉和恋人属于同类。——哈菲兹"

    在爱情中，非理性成分和不理智成分表现尤为突出，一切似乎都无法借助人们的认识来预见、培养和控制。

    波斯诗人哈菲兹说过，醉汉和恋人属于同类：对两类人来说，生活哪怕暂时驱逐理性的光明，也会给人带来欢乐。荷兰文学家埃拉斯姆斯认为，爱情不是理性的胜利，而是**愚蠢的凯歌**——爱情的魅力就在于它的神秘性和自发性，它不问缘由、不顾一切、不计利害，虚幻朦胧。爱情从不考虑后果，或许正因如此，许多人才认为炽热的爱情总是目的。

    千百年来，诗人、作家、哲人、智者、宫廷小丑、讽刺作家，无论是情场上的胜利者，还是被丘比特之箭射伤的恋人，都竞相证明==爱情是疯狂的==。

### 理性主义情爱论

!!! note "把爱情纳入理性与义务的框架"

    一批哲学家站在理性主义的片面立场上规定爱情，认为一切均来自理性，爱情同丧失理智的种种乖戾行为格格不入。

| 哲学家       | 核心命题                                                                                                                                                                                       |
| :----------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **帕斯卡**   | 一切均来自理性，爱情是明智的，与丧失理智的乖戾行为格格不入。（17 世纪法国理性主义情爱论的典型代表）                                                                                             |
| **斯宾诺莎** | 在一切场合，欲念、感情、认识和爱等都是思维着的实体的个人方式；爱产生于我们对事物的观念和认识，事物越美我们越爱。                                                                                 |
| **康德**     | 人与人的关系领域里发挥作用的是无上命令，即普遍的抽象必然性。性生活之所以具有爱情性质，因为它是**有目的、合乎规定**的行为，宗旨是维持种属这一自然目标；爱情只存在于由法律神圣化的婚姻之中，同时体现义务的约束（道德规范和法规）。 |
| **费希特**   | 以唯心主义立场探讨男女关系，认为爱情只存在于神圣的婚姻范围内；爱情按理性的发展规律，由男女双方认识到自己在婚姻中的崇高地位而产生，被这种义务感结合在一起。                                       |

## 弗洛伊德的精神分析

!!! note "里比多与婴幼儿性欲"

    弗洛伊德的精神分析法特别注重所谓的**里比多**，也就是性欲。他认为这种本能在婴儿身上就已经表现出来：婴儿的性欲也寻找对象，一般倾向于最亲近的人，所以男孩通常选择母亲、女孩选择父亲——男孩发育中的第一个爱的对象就是母亲，也可能集中在其他方面，比如哥哥和妹妹之间。这就是里比多自发的、无意识的、幼稚的**固定作用**。

    随着儿童的成长、受教育，**道德检查**便在他们的意识中开始起作用，压制那些表现于早期、但如今已变得可耻的性欲观念。

    在弗洛伊德看来，性欲从一个对象转向另一个对象，是由种种条件直接决定的；性欲经常为被禁忌所禁止的对象、或在生活中不能得到的自然对象，寻求<u>代替物</u>。

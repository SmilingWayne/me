# 经院哲学

经院哲学一词来自拉丁文 `scholasticus`，原意为“学院的思想”。

这个词原来并不专指哲学。中世纪的学院的学术主要包括**哲学**与**神学**，“经院学术”既是哲学，又是神学：<u>它作为哲学史研究对象是经院哲学，作为神学史研究对象是经院神学</u>。

因此，“经院哲学”的确切含义应是：在**公教会（或天主教）学校里传授的、以神学为背景的哲学**。经院哲学之所以构成哲学史的一个完整阶段，原因是它是教父哲学思想的直接承袭，并且与教父哲学一样继承发展了古希腊哲学；另一方面，它又直接地影响了近代哲学，无论是积极的吸收，还是否定性的批判。

经院哲学有**两个基本特征**：一是它以“经院”（即教会或修道院办的学校）为生存环境，二是它以“辩证法”（即亚里士多德所说的论辩推理）为操作原则。

## 安瑟尔谟：上帝存在的“本体论证明”

在《宣讲》的开头，安瑟尔谟说，他的学生们提出的问题使他考虑这样一个问题：“**能否找到不要别的，只要自身，就足以证明上帝真的存在？**” 

经过长期的考虑，他突然想到问题的答案，就是哲学史上著名的上帝存在的“本体论证明”。这个词是康德后来赋予它的名称，其意义是仅依赖于概念的分析而不依赖于经验事实的证明。在安瑟尔谟看来，人人都有“上帝”的观念，只要弄清这一观念的意义，就能理解上帝必然存在的理由。这就是他所说独立的充足的证明的意思。

《宣讲》中的证明被表述为下面一个三段式推理：

- 大前提：上帝是不能被设想为比它更伟大的东西。

- 小前提：不能被设想为比它更伟大的东西不仅存在于思想之中，而且也
实际上存在。

- 结论：上帝实际上存在。

!!! info "解释"
    安瑟尔谟的逻辑是，“不能比它更伟大的东西”，如果被设想为仅在心中存在，<u>那么，心灵就会设想另外一个观念，它在心中与现实中都是不能比它更伟大的</u>，它比仅仅只是在心中“被设想为不能比它更伟大的东西”更伟大。这样一来，仅仅在心中“被设想为在心中和现实中都不能比它更伟大的东西”就是一个自相矛盾的现念。

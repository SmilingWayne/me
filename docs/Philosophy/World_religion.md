# 世界宗教

- 图书馆借书阅读读完的。

涉足宗教学以来第一本"大开眼界"的书，大学以来第一本读满了续借30天期限的书。以一种蛮不讲理的方式扩充了我对世界宗教的了解。内容十分翔实充分，个人认为做到了最广阔的宗教汇总和简介。按照地理位置不同介绍不同地区的宗教，略带介绍了各个地区宗教的发展历程。难能可贵的是抛弃了过分深奥的神学争论。

> 如果你看我的书评比较多会发现其实我十分反感深奥且乏味的神学争吵，我更想探求宗教这种东西背后的历史因素、政治因素的影响，类似于"Why"，为什么是这样？什么导致了这个？什么让大家的理解有了不同？如果处在另一些不同的环境（地理？人文？政治？经济制度？）下，情况会怎样？我更想分析一些难以解释的现象的可能原因。具体一点讲我想要的不是单纯的文字层面的咀嚼，我想要看到文化层面的分析和解释。

如果是对单个宗教特别感兴趣而不想要从广度入手的读者，这本书可以作为一个利用效率比较多的字典，你可以潦草地了解一些"事实"，但是你的认识也是仅限于"潦草"的，这是由本书的内容所决定的。

不过这本书对我有一个额外的促进就是，教会我从一个发展和动态的角度去审视不同地区的宗教发展情况————譬如拉丁美洲的天主教和原始宗教，譬如非洲的原始宗教到加勒比海地区的传播等。都是足够发人深省的。

## 摘记
-----

### 一、宗教流派与神学思潮

**基督教系统：**

- **基督教自由主义神学**（20世纪）：试图在现代科学时代保持信仰可信性
- **哈维·考克斯**（Harvey Cox）：基督教无神论思想——通过放弃信仰来取悦情感和行为，是自由主义神学的最终结果
- **解放神学**（拉丁美洲）：天主教流派，以马克思主义政治经济理论解释圣经，认为信仰是政治的根基，耶稣即解放者。关联人物：玻利瓦尔（Simón Bolívar）
- **美国基要主义**（Fundamentalism）：基督教原教旨主义，按圣经原文理解宗教
- **福音派**：代表——马丁·路德·金
- **基督教传播关键因素**：圣经译介与本土化——与其大张旗鼓鼓动，不如潜移默化改变
- **近现代的犹太教**（待补充）

**伊斯兰系统：**

- **马赫迪**（Mahdi）："被真主引领走向正路的人" → 马赫迪起义：号召恢复伊斯兰正统与纯洁，有原教旨主义倾向
- **伊斯兰世界 vs 战争领域**（Dar al-Islam / Dar al-Harb）：后者为武装斗争与吉哈德（Jihad）的场所
- **巴哈伊信仰**（待补充）
- **真纳**（Jinnah）：巴基斯坦建国者

**印度宗教系统：**

- **大乘佛教**（摩诃衍那 / Mahayana）：佛能渡无量众生到彼岸；**小乘佛教**（Hinayana）
- **密教哲学**
- **耆那教、印度教、婆罗门教、邪命外道**（Ajivika）
- **神的人格化：梵**（Brahman）/ 神"无形无性"，但人可通过自身内部证悟到神
- **维维卡南达**（Vivekananda）：在印度，基督教、印度教、耆那教、伊斯兰教的终极混合体
- **甘地**（Gandhi）：戒杀（Ahimsa）的政治化阐释

**其他宗教 / 融合宗教：**

- **琐罗亚斯德教（拜火教）**：善恶二元对立，善神马自达（Ahura Mazda）必胜；其天使/魔鬼描述、末日审判/末世观念被基督教继承
- **锡克教**（Sikhism）："学生/信徒"之意，伊斯兰教（虔信教）与印度教（苏菲派）交叉融合，强调人人平等
- **越南高台教**（Cao Dai）：大杂烩宗教，除本土神外，东西方文学家政治家也被供奉
- **非洲本土宗教**：泛非洲主义、虔诚主义、浓厚的祖先崇拜痕迹
- **太阳舞 / 鬼魂舞**：北美原住民宗教实践

### 二、历史事件与政治背景

- **1919美国禁酒令**：催生黑手党与地下酒馆
- **雅利安人**（Aryan）：出自波斯古典史诗，游牧民族，从中亚北部侵入印度次大陆；万字符本为雅利安太阳神符号；希特勒在《我的奋斗》中宣扬"高贵的雅利安人"实为误解
- **凯尔特人**（Celts）：红发，分布于法国布列塔尼与英国
- **赫梯帝国**（Hittite）：土耳其一带，与埃及争霸，公元前16世纪攻占巴比伦
- **埃赫那吞改革**（埃及）：表面一神教改革（以阿吞神代阿蒙神），实质权力斗争；遭神庙势力阻挠，在图坦卡蒙时期失败
- **斯瓦西里文化**：非洲-阿拉伯社会
- **金沙萨**（原名利奥波德维尔）：比利时殖民地；关联——《利奥波德国王的鬼魂》
- **祖鲁人**（Zulu）
- **七年战争**：法国与荷兰的冲突
- **英国东印度公司**：功利主义对传教士的影响（道德和法律应把幸福扩展到最大限度）；资本主义兴起 + 世界经济体系 + 印度民族主义兴起
- **戈登将军**（Charles Gordon）：指挥洋枪队攻击起义军，死于苏丹喀土穆战役
- **犹太复国主义**：从阿拉伯人视角看，是西方殖民主义的延续
- **蒙固王**（King Mongkut，泰国）：佛教改革，建立佛学院；法轮作为宗教观念
- **波尔伯特 + 乔森潘**（红色高棉）：关联——"肤浅的马克思主义"，部分地区马克思主义宣扬不到位，共产党人认识不足

### 三、经典与文献

- **阿维斯陀**（Avesta）：琐罗亚斯德教圣书，古代波斯语，阿契美尼德王朝末期（BC4世纪末）
- **梨俱吠陀**（Rigveda）：印度最古老吠陀经典
- **奥义书**（Upanishads）：印度哲学经典
- **翠堵波**（Stupa）：佛教建筑
- **示巴女王**：旧约人物，与所罗门王关联
